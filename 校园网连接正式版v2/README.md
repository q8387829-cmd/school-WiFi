# 校园网连接正式版 v2

版本：**2.0.0**。本发行包把启动入口、程序、维护工具和说明分开，包含运行所需的应用脚本、界面资源和原生宿主，可在满足系统依赖的 Windows 电脑上完整解压后运行，不依赖 v1 目录。

## 开始使用

1. 将整个压缩包解压到当前用户可写、准备长期保留的位置，保持目录层级完整。不要在压缩包预览中直接运行。
2. 双击 [check-release.cmd](<check-release.cmd>) 检查系统依赖和发行文件。未使用过的干净目录可在命令行运行 `check-release.cmd -Strict`。
3. 双击 [打开校园网助手.cmd](<打开校园网助手.cmd>)。在“账号与设置”保存账号、运营商和密码，再按需开启自动监测。
4. 需要登录 Windows 后自动运行时，在界面中启用“开机启动助手”。只运行一个版本；启用 v2 前请先退出 v1。

“打开助手时自动监测”在没有已存设置时默认开启。已有账号并启用该选项时，打开程序可能自动提交校园网认证。关闭窗口会驻留托盘；彻底退出请使用托盘退出操作。

## 这一版的变化

- 启动、唤醒和有效本地网络变化可进入 90 秒恢复观察期，临时失败最多提供 3、5、10 秒三次快速重试间隔，之后按累计失败次数使用 15、30、60、120、300 秒退避。
- 未分类认证拒绝累计到 3 次后，每次失败进入 300 秒冷却，到期仍会自动尝试；检测到在线或账号记录更新后才重置累计状态。明确账号、密码、验证码或其他需人工处理的错误保持自动提交暂停。
- 界面显示恢复状态和下一次自动重试倒计时。“立即检查”成功不再弹出重复确认提示；监测关闭时它只读取状态，监测运行时可请求尽快复查并仍受暂停与冷却约束。
- 根目录只放常用入口，程序集中在 `app/`，维护命令集中在 `tools/`，说明集中在 `docs/`。

具体时间是调度间隔，不是恢复时长承诺。网络、认证服务器、休眠和系统调度可能延长实际等待。

## 运行条件与独立运行范围

需要 Windows 10/11 **x64**、Windows PowerShell **5.1**、.NET Framework **4.8 或更高**、可用的 Windows 脚本宿主，以及 Microsoft Edge **WebView2 Evergreen Runtime x64**。可从 [微软 WebView2 官方页面](https://developer.microsoft.com/microsoft-edge/webview2/)获取运行库；本包不安装依赖。

包内 WebView2 SDK DLL 不能替代浏览器运行库。无需 Node.js、npm、Python、.NET SDK 或 C# 编译器。程序会写入自身的 `app/data/`、`app/CampusNetwork-Lens/state/`，并把宿主及 WebView2 SDK 文件按哈希发布到当前用户的 `%LOCALAPPDATA%/CampusNetworkLens/runtime/`；因此它是完整目录发行，不是单文件、只读或零系统依赖应用。

本工具仍面向当前学校的 Dr.COM 认证部署（认证地址 `10.10.102.50`，相关端口 `80`、`801`），不是任意校园网通用客户端。界面不依赖公网 CDN，实际认证需要能访问学校认证服务。
