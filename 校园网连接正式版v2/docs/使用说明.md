# 使用说明

## 安装与打开

1. 完整解压发行包到当前用户可写的固定目录。不要只复制 EXE，也不要拆分 `app/` 内的文件。
2. 运行 [check-release.cmd](<../check-release.cmd>)。检查只读取程序文件、系统依赖及元数据，不读取账号、不访问校园网、不安装组件。
3. 运行 [打开校园网助手.cmd](<../打开校园网助手.cmd>)。Windows 可能按来源、组织策略或安全设置限制脚本；请先确认发行来源和检查结果，再按自己的系统管理要求处理。
4. 在“账号与设置”填写账号、运营商和密码。同一账号与线路留空可沿用原密码；首次保存或更换账号、线路需要输入密码。已存密码不会回填到输入框。
5. 在“连接”页开启“自动监测与重连”，程序在确认未登录后按策略尝试认证。

没有已存偏好时，“打开助手时自动监测”默认为开启。迁移账号后首次打开可能立即尝试认证；只想查看界面时应先关闭该选项，具体见[迁移说明](<迁移说明.md>)。

## 连接状态与立即检查

- “校园网已连接”表示近期有效的认证检查确认在线，不保证所有互联网目标可访问。
- “尚未确认认证状态”表示证据不足、状态过期或后台暂不可用，不等于确认断网。
- “正在自动恢复连接”显示恢复观察剩余时间；“n 秒后自动重试”显示下一次调度时间。无需连续点击。
- 自动监测未开启时，“立即检查”只访问认证状态，不提交账号密码。
- 自动监测运行时，“立即检查”会请求后台尽快复查，若确认未登录且策略允许，后台可能重试认证。请求成功时不再弹出重复提示；失败仍显示错误。

启动、系统唤醒和有效本地网络变化可触发 90 秒恢复观察期。临时失败在恢复期最多使用 3、5、10 秒三次快速重试间隔；普通退避按累计失败次数使用 15、30、60、120、300 秒。账号拒绝、服务端限流和安全冷却不会被唤醒、网络抖动或重复点击绕过，完整规则见[更新说明](<更新说明.md>)。

## 账号错误与冷却

明确的账号或密码错误、验证码要求等会暂停自动提交。监测继续复查状态；更正并保存账号记录，或完成网页登录后被检测为在线，才会解除本轮暂停。不要通过频繁重开程序来反复提交错误账号。

无法分类的认证拒绝累计到 3 次后进入 300 秒冷却，到期自动重试。若之后仍遭拒绝，每次仍冷却 300 秒；冷却到期本身不会清零计数，在线或账号记录更新才重置。服务端限流至少等待 60 秒，并尊重可解析的更长 `Retry-After`。

## 窗口、托盘与开机启动

关闭窗口会驻留托盘；双击托盘图标重新打开。需要完整退出或移动目录时，使用托盘的退出操作，并确认后台监测已停止。

“开机启动助手”注册的是当前 Windows 用户的启动项，不需要变更系统服务。v1 与 v2 使用同名启动项，最后一次成功启用的已识别副本取得启动入口；禁用只移除当前副本拥有的入口。不要同时运行两个版本。移动已启用开机启动的目录前，先从原位置禁用，移动完成后再从新位置启用。

## 维护工具

下列命令只作用于本发行目录对应的程序；它们不是安装程序。除两项只读发行检查外，请仅在需要执行对应操作时运行。

| 工具 | 行为 |
| --- | --- |
| [停止自动监测](<../tools/停止自动监测.cmd>) | 停止此副本的监测并记住暂停；不会注销当前校园网。 |
| [启用开机启动](<../tools/启用开机启动.cmd>) | 使用已存账号为当前 Windows 用户注册此副本；可接管已识别旧版的同名入口。 |
| [禁用开机启动](<../tools/禁用开机启动.cmd>) | 只移除此副本拥有的入口，不停止已经运行的程序。 |
| [检查连接](<../tools/检查连接.cmd>) | 访问认证服务器读取当前状态，不提交账号密码。 |
| [网络诊断](<../tools/网络诊断.cmd>) | 检查本地网络和认证端口，会发起网络请求，不提交登录。 |
| [环境检查](<../tools/Check-Environment.ps1>) | 只读检测运行条件与关键文件是否存在，不启动应用。 |
| [完整性检查](<../tools/Verify-Release.ps1>) | 比对发行清单，不读取运行数据内容。加 `-Strict` 检查干净发行目录。 |

## 数据、排障与分享

账号与设置保存在 `app/data/`；账号文件含账号名和使用 Windows DPAPI 加密的密码。浏览器配置、缓存和临时诊断在 `app/CampusNetwork-Lens/state/`。不要将这两个目录打包分享，也不要在求助时发送账号文件。运行日志或诊断可能包含网络环境信息，分享前需检查并删除个人字段。

- 无法打开：先运行根检查工具，确认完整解压、Windows x64、PowerShell 5.1、.NET 4.8+ 和 WebView2 Runtime。检查成功仅证明所列依赖与文件存在，不替代实际桌面启动测试。
- 一直显示后台未连接：检查程序文件完整性和目录写入权限，然后完整退出后重新打开；保留故障时间以便定位。
- 已连接网络但无法认证：先查看界面原因和“网络诊断”，确认当前网络能访问学校认证服务，再检查账号与运营商。
- 正在倒计时：等待自动尝试；若显示账号需处理，则更正保存或网页登录，不要靠连续点击解除暂停。

本发行使用 v1 原生宿主。主程序自身的签名、版本和二进制出处见[发行与验证](<发行与验证.md>)。
