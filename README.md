# 校园网连接正式版 v2

最新正式版：**v2.0.0**，GitHub 发布日期：2026-11-12。

面向 Windows 的 Dr.COM 校园网认证与自动重连助手，提供连接状态、账号设置、恢复倒计时、网络诊断和托盘入口。当前适配学校认证服务 `10.10.102.50`，其他学校需要另行适配。

## 下载与使用

- [最新正式版与下载附件](https://github.com/q8387829-cmd/school-WiFi/releases/latest)
- [下载 v2.0.0 完整 ZIP](https://github.com/q8387829-cmd/school-WiFi/releases/download/v2.0.0/school-WiFi-v2.0.0-windows-x64.zip)
- [下载 ZIP 的 SHA-256 校验文件](https://github.com/q8387829-cmd/school-WiFi/releases/download/v2.0.0/school-WiFi-v2.0.0-windows-x64.zip.sha256)

1. 下载完整 ZIP 并解压到当前用户可写、准备长期保留的位置，保持目录层级完整。
2. 在 `校园网连接正式版v2` 文件夹内运行 `check-release.cmd` 检查依赖与文件。
3. 双击 `打开校园网助手.cmd`，在“账号与设置”填写自己的账号、运营商与密码。
4. 按需启用自动监测与开机启动；切换前先退出旧版。

已有账号并启用“打开助手时自动监测”时，程序可能自动提交校园网认证。关闭窗口会驻留托盘，彻底退出请使用托盘菜单。

## 运行条件

Windows 10/11 x64、Windows PowerShell 5.1、.NET Framework 4.8+、Windows 脚本宿主，以及 [Microsoft Edge WebView2 Evergreen Runtime x64](https://developer.microsoft.com/microsoft-edge/webview2/)。不需要 Node.js、Python 或开发工具链。

这是需要完整解压并满足系统依赖的目录发行。包内 WebView2 SDK DLL 不能替代浏览器运行库。

## v2 的主要变化

- 启动、唤醒和有效本地网络变化可进入恢复观察期，临时失败最多使用 3、5、10 秒三次快速重试间隔。
- 后续失败按累计次数退避；未分类拒绝达到阈值后进入 300 秒冷却，明确账号或验证码错误保持暂停。
- 界面显示恢复状态和下一次重试倒计时，“立即检查”成功后保持安静。
- 程序、维护工具与说明分别放在 `app/`、`tools/`、`docs/`，附带文件完整性校验。

间隔是调度策略，不是实际恢复时长承诺。状态未知时不会据此提交账号密码。

## 个人数据

仓库与下载包不包含个人账号、密码、令牌、运行日志或浏览器缓存。自己的账号记录和设置保存在本机 `app/data/`，浏览器状态保存在 `app/CampusNetwork-Lens/state/`，这两个目录均已通过 `.gitignore` 排除，请勿强制加入版本控制或手动上传。

密码使用 Windows DPAPI 在本机加密保存，账号字段仍是普通文本；学校认证接口使用 HTTP，本机加密不会改变请求的传输方式。
